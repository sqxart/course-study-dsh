# 知识总结：只写考试会考到的知识与概念

课程内容落两份文件，**不许混**：

| 文件 | 内容 | 谁写 |
|---|---|---|
| `knowledge/<course>/bank.json` / `bank.md` | 题库：题面、选项、我的答案、正确答案、得分 | `scripts/quiz_bank.py build`（确定性） |
| `knowledge/<course>/knowledge.md` | 知识总结：**这一节涉及的考点知识**（概念、判断依据、易混） | 每节一个 agent 读该节完整字幕写成 note，再由 `scripts/knowledge_doc.py build` 拼装 |

## 0. 写什么、不写什么

- **写**：这一节里能变成考题的知识与概念 —— 定义、分类、判断依据、因果关系、
  易混术语的区别、结论性的判断。
- **不写**：流水账式的「本节讲什么」、按视频顺序复述的「要点 1..N」、课堂事务、
  老师的个人经历、与考点无关的例子。
- **不写**：测验题干和答案原文 —— 那在 `bank.md`。这里写的是"支撑这道题的知识"。
- 只写字幕里讲过的；字幕没讲的原理、数据、结论一律不补。

## 1. 一节 note 的格式（agent 产出，`notes/<course>/<section>.md`）

```markdown
**考点知识**

1. **公地的悲剧 / 产权经济学视角**（00:01:17–00:01:36）
   - 含义：公共资源因产权边界没有界定，谁都能用、没人爱护，因而被过度使用。
   - 怎么考：问"从什么视角看"→ 产权经济学/法律经济学；问"原因是什么"→ 产权不明晰。
   - 易混：福利经济学把同一现象叫"外部性"（一些人使用、成本由别人承担），选项常把两者并列。

2. **视角决定解决方案**（00:06:39–00:07:33）
   - 含义：归因不同，法律与政策方案就不同；产权视角导向私有化，福利经济学视角导向政府管制。
   - 怎么考：给一个视角问它会推出哪种方案，或反过来给方案问它出自哪个视角。
   - 易混：把"增强学龄前教育"当成法律视角的方案 —— 它是人口学/儿童视角的方案。

**概念表**

- 公地的悲剧：产权不明晰导致的公共资源过度使用。
- 外部性：一些人使用资源、成本由另一些人承担。
- 庇古经济学：福利经济学传统，主张政府管制、税收调节。
```

硬性要求（`knowledge_doc.py check` 会卡）：

- 必须含 `考点知识` 与 `概念表` 两段（顺序如此）。
- `考点知识` 至少 5 条编号，每条**必须带时间戳**（单点或区间都行，如 `(00:01:17–00:01:36)`）。
- 正文至少 300 字。
- 每条考点要有 `含义` 与 `怎么考` 两行；`易混` 可选但强烈建议。
- **不许**出现 `本节讲什么` / `要点` / `本节结论` 这类总结段（旧格式，已废）。
- **不许**复述题目：出现 `【单选题】` / `我的答案：` / `正确答案：` 直接判不合格。
- 课堂事务最多一句带过，不占考点条目。

## 2. 调用方式（一节一个 agent，可并行）

给 agent 的输入：

- 字幕：`runs/bank/subs/<course>/<section>.srt`
- 该节的题目（题干 + 正确答案，从 `bank.json` 取）——让它知道"考什么"，但**不许把题目抄进 note**。
- 产出：`runs/bank/notes/<course>/<section>.md`

不碰浏览器，所以可以并行。每个 agent 写完自己跑
`python scripts/knowledge_doc.py check <note>`，不合格就补写。

## 3. 拼装

```powershell
python scripts/quiz_bank.py build --nodes runs/bank/nodes/paper-writing --course paper-writing `
  --title 示例课程11 --expected runs/bank/expected-paper-writing.json
python scripts/knowledge_doc.py build --bank knowledge/<course>/bank.json `
  --notes runs/<task>/notes/<course>
```

- 章标题、节标题、节号顺序都取自 `bank.json`，note 里不要再写标题。
- 没有 note 的节输出「（本节暂无字幕总结，待补；题目见 bank.md）」，不拿题目文字凑数。
- 每节末尾自动加一行「本节测验 N 题，题面与我的答案见 `bank.md`」。

## 4. 质量判据（拿这两条卡）

1. 一个没看过视频的人，读「考点知识」能不能直接答这一节的测验题？
2. 随机挑一条，按时间戳回看那 10 秒，视频里讲的是不是这件事？
