# 知识总结：从字幕写成能复习的文档

课程内容落两份文件，**不许混**：

| 文件 | 内容 | 谁写 |
|---|---|---|
| `knowledge/<course>/bank.json` / `bank.md` | 题库：题面、选项、我的答案、得分、对错 | `scripts/quiz_bank.py build`（确定性） |
| `knowledge/<course>/knowledge.md` | 知识总结：这一节讲了什么、概念、判断依据、示例、结论 | 每节一个 agent 读该节完整字幕写成 note，再由 `scripts/knowledge_doc.py build` 拼装 |

`review.md` 那套「用选项词去匹配字幕、只摘几个词」的做法已经废弃——它摘出来的是
`[00:01:17] 那么迫切需要一种高带宽` 这种残句，复习时没有信息量。**数据从来不是问题**：
121/157 节有全文字幕，问题是写法。

## 1. 一节 note 的格式（agent 产出，`notes/<course>/<section>.md`）

```markdown
**本节讲什么**
3–5 句：这一节要解决什么问题、按什么顺序讲、结论是什么。读完这段就该知道全片在讲什么，
不要出现「介绍了……相关内容」这种空话。

**要点**
1. **小标题**（00:01:17）：完整的一句话或两三句，说清「是什么、为什么、怎么用」。
2. **小标题**（00:03:40）：……
（6–12 条，按视频顺序，覆盖全片的主要论证，不是只挑考点）

**关键概念**
- 术语：本节给出的解释（用本节的说法，不要换成教材定义）
- ……

**易混淆 / 易错**
- 本节里容易搞反、容易混的两个说法，以及区别；没有就写「无」

**本节结论**
1–2 句，能单独当复习卡片用。
```

硬性要求（`knowledge_doc.py check` 会卡）：

- 必须含 `本节讲什么` / `要点` / `关键概念` / `本节结论` 四段。
- `要点` 至少 5 条编号，每条**必须带时间戳** `(mm:ss)`；全文至少 3 个时间戳。
- 正文至少 400 字。
- **不许复述题目**（出现 `【单选题】`/`我的答案：` 直接判不合格）——题目在 `bank.md`。
- **只写字幕里讲过的**：字幕没说的原理、数据、结论一律不补；不确定就不写。
- 字幕是语音识别/人工转录稿，有口误和同音字时按上下文改正明显错字，但不得改变原意。
- **课堂事务不是知识**：作业要求、查重、旁听登记、点名、考试安排、答疑闲聊，最多在
  「本节讲什么」里用一句带过，**不占要点条目**。一门课的事务性内容往往连续好几分钟，
  写进要点会把真正的知识挤掉。
- 时间戳能用区间就用区间（`00:01:16–00:06:25`），不要在一句话后面叠两个括号时间。
- 一句话讲清主谓宾：写「智能汽车在分布式线控下需要高带宽」，不写「老师提到了高带宽」。

## 2. 调用方式（一节一个 agent，可并行）

给 agent 的输入只有两个路径和上面的格式要求：

- 字幕：`runs/bank/subs/<course>/<section>.srt`
- 产出：`runs/bank/notes/<course>/<section>.md`

不碰浏览器，所以可以并行（本阶段试过 3 路并行没问题）；每个 agent 写完自己跑
`python scripts/knowledge_doc.py check <note>`，不合格就补写，不要交残稿。

## 3. 拼装

```powershell
python scripts/quiz_bank.py build --nodes runs/bank/nodes/course-example --course course-example `
  --title 无人驾驶车辆 --expected runs/bank/expected-course-example.json
python scripts/knowledge_doc.py build --bank knowledge/course-example/bank.json `
  --notes runs/bank/notes/course-example
```

- 章标题、节标题、节号顺序都取自 `bank.json`，note 里不要再写标题。
- 没有 note 的节输出「（本节暂无字幕总结，待补；题目见 bank.md）」，不拿题目文字凑数。
- 每节末尾自动加一行「本节测验 N 题，题面与我的答案见 `bank.md`」，把两份文件对上但又不重复内容。

## 4. 质量判据（拿这两条卡）

1. 把「本节讲什么」单独抽出来读，**不看作题也能知道这节讲了什么**。
2. 随机挑一条要点，按时间戳回看视频那 10 秒，**说的是同一件事**（不是同义词，不是推断）。
