# 回退与隔离

本技能只改自己的源码、安装副本和 `local/`。`course-study-v2`（ZCode/Codex 共用源）及其安装副本不由本技能安装、卸载或覆盖。

## 切换步骤

1. 保存本技能的断点：账号别名、课程键、当前节点、进行中的测验与已有授权。
2. 核对平台实际状态，特别是提交是否已生效。结果未知时先查提交记录，不再提交一次。
3. 确认本技能的浏览器与执行器已停止，避免两套同时操作同一账号。
4. 由接手的技能或人工读取平台状态后继续；本技能状态只作交接信息，不覆盖对方的 state 或课程配置。

## 读题与通道失败

读题失败时可退回当前明文、受支持截图、原有页面字体渲染与人工复核；字体和题目要同批。
列表解析失败退回当前页面快照，不把空解析当无任务。保留失败样本供后续分析。
缺少受支持的浏览器通道时只做离线工作，并写明缺口，不另开隐藏控制通道。

## 旧 Runner 与资料

旧 Runner、登录方式和依赖继续保留原目录；索引只保存路径，不复制密码、cookie 或登录态。
需要回退时明确选择对应技能并遵循其实际接口与已有任务授权，不由本技能猜测参数或自动启动。
全新机器上没有旧技能时，不能声称存在完整旧版回退；仍可使用当前明文、截图、正常播放和人工复核路径。

`scripts/official_seek.mjs` 是独立辅助模块，只能对已经建立的受支持 Playwright 会话操作中国大学MOOC 原生进度条。
它不包含登录、课程发现、完成核验或自动上报，不能独立证明任务完成。
