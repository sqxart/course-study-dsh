# 平台技术笔记

这里保留可复用页面机制与处理配方。个人课程名、账号、成绩、实例标识、运行日期与逐节点记录只放在本地 `runs/`。
执行顺序见 [快速配方](quickstart.md)，通道和调用边界见 [运行说明](dsh-runtime.md)。

## 任务点与目录

- 视频与章节测验可能分别计任务点；弹题不能代替章节测验。完成只看新加载目录的 `.catalog_points_yi`、`icon_Completed` 或平台结果标记。
- `input.jobUnfinishCount` 与目录角标是加载时快照；刷新后再核验。标题末尾也可能有数字，勿用行尾数字代替专门的计数元素。
- 多视频节点要枚举所有视频帧，按几何位置依次播到 `ended`。若要求总时长 90%，只播第一段可能不达标；evidence 记录各段时长与总和。
- 新版课程门户先点「章节」才加载 `studentcourse` 帧；章节、作业和考试可能各有 iframe。`ensureToc()` 负责目录就绪，不能因初始无目录帧判定无内容。
- 有的课将测验叫「章节测试」，检索词须含 `测试`。剩余任务点为 0 的已提交测验仍可只读取数；没有测验入口的内容节点不能生成题库。
- **页签排布不固定**：多数节是「视频 / 章节测验」两页签，但**每章第一节**常多一个「学习目标」（三页签）。
  按 innerText 匹配页签（含「视频」「章节测验」），不要固定点 `li#dct2`——在三页签节点上会点进视频，然后永远等不到答题帧。
- **行尾没有点数 `span` 时记 0，不记 `null`**：已清节只剩节名，`catalog_points_yi` 取不到文本；证据里写 `null` 会被校验器当类型错误，
  拆包时统一归一化为 `0` 并补一条 deviations 说明。
- **第二证据源**：学习记录 → 章节任务点 → 详情（`stat2-ans`）逐条给出每个资源的完成时间与分数，
  是目录行尾之外唯一能回答「这个视频是不是本次看完的」的地方；音视频累计观看通常略大于资源总时长，差得离谱说明有节点被重播。
- **`.catalog_sbar` 会整体错位**：它把不带编号的「导论」也编成 `1.1`，整表比页面节号大一位；节号只从行首可见文字
  （`^\d+(?:\.\d+)+\s+`）解析，不要用 sbar 或 `cur…` 这种 DOM id。
- **`catalog_points_yi` 消失 ≠ 立刻可信**：刚提交完回目录，span 可能还没渲染掉就读到 `null`；**批末必须重读一次**，
  再看 `.catalog_state`（`icon_yiwanc` = 已完成）和行内 `knowledgeJobCount` / `jobUnfinishCount`。
- **`video.ended` 但行尾仍剩点 = 平台没记账**：重播整段，`ended` 后**停留 ≥25 s** 再切页签；只重播，不重开测验、不二次提交。
- **`stat2-ans` 与目录点数必须相等**（含开工前已完成的点）；不等时以 `stat2-ans` 为准，按差值回目录找脏节。

## 测验与答案来源

- 提交成功、分数与任务点是不同信号。低分可能点亮，也可能不点亮，只按平台完成标记判定。
- 待作答态题面可能使用混淆字体，提交后的结果页才是明文。正确答案是否可见由教师设置，隐藏字段也可能没有答案键。
- 正解可见记 `correct_source: page`；平台未给时留 `null`，满分题才可按既有规则反推。外部题库只能作为明确标注的参考。
- 只读取题时记录 `retake_present`，不点击重做。未满分是否重做由 `local/private.toml` 的 `redo_once` 和当前授权决定。
- 重做预填上次答案；修正时设定精确集合。显示字母与 `span[data]` 的关系须在当前页回读，不能假设同序。
- 提交链是 work 帧 `.btnSubmit` → studentstudy 帧可见确认层 → 结果页。只有看到「重做 (剩余 N 次)」入口才认为有额度；恢复导航失败先回目录核对，不盲目重复提交。

## 取题库与知识总结

- 课程卡可能开新标签；维持单标签，按运行说明优先复用当前标签与平台生成的链接。签名入口会轮换，不重放旧链接。
- `bank_subs.py --expect` 的 `NO_SUBTITLE` 也可能表示 capture 尚未取齐。等预期节点落齐后再判覆盖率。
- 浏览器 `filename` 按 profile 根解析；派活时传已生成的相对路径，不让子 agent 去仓库找不存在的 `bank/*.js`。
- `quiz_bank.py build`、`knowledge_doc.py build` 的 `WROTE ...` 在 stderr；PowerShell 5.1 可能包装成 `NativeCommandError`，结合退出状态和 stdout 的 `COURSE=...` 判断产物。
- 节点原文可能来自字幕、ASR、富文本或文档页图 OCR；不能把无字幕直接判成无内容。

## 无字幕与 OCR

- 允许 ASR 时，按页面提供的签名媒体链接取数并转写；默认 90 秒分块，避免长块重复。下载支持 Range 续传，按服务要求携带 `Referer`。
- **字幕优先，且跨域**：`allsubtitle` 给的 SRT 在 `cs.ananas.chaoxing.com/support/<id>.srt`，页面内 `fetch` 会被 CORS 挡；
  用本机 HTTP 直接拉下来落成 `subs/<节>.srt`（20–26 KB、带时间轴）。**有字幕就不要开 ASR**；
  用户明确禁用 ASR 时，无字幕节按学科判断并标 `low_confidence`，不下载 mp4、不转写。
- 混淆题面截图后走 `quiz_ocr.py`；字体映射按页随机，跨页码位表可能静默解错。
- 旧弹题点 `input[type=radio]` 并回读 `checked`；v24 测验常用 `li[qid]`，回读隐藏答案 token 与 `aria-checked`。判断题 token 是 `true/false`，不要拆成字符集合。

## 播放、窗口与焦点

- 旧播放器可能失焦暂停；v24 可在最小化下继续播放。最小化后核验 `IsIconic`、`currentTime` 和截图可读性。
- 窗口按 `--user-data-dir` 识别。`scripts/browser_window.py` 只处理带 `.dsh` 标记的浏览器，支持 `list/minimize/restore/watch`。
- 节点可能只在 iframe 内导航；用 `studentstudy` 帧判状态，回目录使用页面生成的 `a.subBack` 地址。
- 锁速课接受 1x。倍速按钮常**起播后**才可见；菜单可能只对已完成视频开放，也可能一门课里只有前几节能选倍速——
  **逐节记录 `rate/rate_source`，不要给整门课贴一个 locked**。按当前菜单与读回速率记录，不对抗播放器覆盖。
- 视频未起播时 `duration` 或媒体资源可能为空；静音并用官方控件起播后再读。`ended` 不证明平台已保存。
- **单次调用预算 ≤ `toolCallTimeoutMs − 60 s`**（本机 300 s → 240 s）：进节点、等帧、收尾另有 20–60 s 开销，
  280 s 会稳定撞超时。**超时不是失败**：视频往往还在页面里继续播，先读一次状态再决定续不续；
  重跑起播脚本会把同一节从头再放一遍。
- 运行器会拒绝**完全相同**的连续工具调用；需要连续观察时，生成 2–3 个预算不同的观察器轮换使用。
- 弹题有的播放器答对才关层，有的提交即关闭且无 verdict；静态判分文案不能作证据。平台未公布正确答案时保持空值。

## 风控与恢复

- 跳页间隔至少 4 秒，每轮最多 10 跳；从目录进入，不拼直链绕过包装页。
- 日上限模板可能常驻且 `display:block`，按 `getBoundingClientRect()` 可视几何判断；提交确认层也要过滤隐藏副本。
- 验证码、9010、多终端提醒、日上限等按运行手册停止条件处理。多账号分别保留现场、登录态和证据。
